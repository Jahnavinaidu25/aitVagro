## Run Locally

### Prerequisites
- Node.js

### Installation

1. Install dependencies:

   ```bash
   npm install
   ```

2. Set your `GEMINI_API_KEY` in `.env.local`.

3. Start the development server:

   ```bash
   npm run dev
   ```
